# 心電図トレーナー ICU EDITION

**▶ ブラウザですぐ使う: https://chestnut8811-star.github.io/ecg-trainer-icu/**

重症病棟(ICU/CCU/HCU)の看護師向けモニター心電図トレーニングアプリ。
ベッドサイドモニターを模した**リアルタイムに動く心電図波形**で21種類の調律・不整脈を学び、クイズで判読力と初期対応を鍛えます。

## 使い方(いちばん簡単)

**`心電図トレーナー.html` をダブルクリックするだけ**で、ブラウザが開いてそのまま使えます。
サーバーやインストールは不要です(JS/CSSをすべて1ファイルにインライン化済み)。

- 学習履歴はそのブラウザのlocalStorageに保存されます
- オフラインでも動作します(フォントのみオンライン時にWebフォントを使用、オフライン時はシステムフォントで表示)
- 配布はこのHTMLファイル1つをコピーするだけでOK

## 開発者向け起動方法

```bash
npm install
npm run dev      # 開発サーバー (http://localhost:5173)
npm run build    # 型チェック + 単一HTMLビルド (dist/index.html)
npm run preview  # ビルド結果のプレビュー
```

`npm run build` は vite-plugin-singlefile により全アセットをインライン化した
単一の `dist/index.html` を出力します(これをコピーしたものがルートの `心電図トレーナー.html`)。

### デプロイ(GitHub Pages)

`docs/index.html` がそのままGitHub Pages(mainブランチ `/docs`)で配信されます。
更新手順:

```bash
npm run build
cp dist/index.html docs/index.html
cp dist/index.html 心電図トレーナー.html
git add -A && git commit -m "更新" && git push
```

## 機能

### 1. 波形ライブラリ
- 21種類の波形を6カテゴリに分類(基本調律/期外収縮/上室性/房室ブロック/致死性/虚血・電解質ほか)
- 実機モニター風のスイープ描画(消去バー方式・25mm/s・10mm/mV相当)
- モニター音(SOUNDボタン): QRS同期音「ピッ」+ 致死性波形では高優先度アラーム音(IEC 60601-1-8風の5連音)を自動再生
  - AFでは不整な同期音、VF・心静止では同期音が消えてアラームのみ、と聴覚でもリズムを学べる
  - 音設定はライブラリ⇔クイズ間で維持(クイズ中はアラーム音オフで答えバレ防止)
- 画面フリーズ(FREEZE)・心拍数のリアルタイム算出
- 各波形に「判読のポイント」「簡易解説」「看護のポイント」「発見時の初期対応」を収載
- 致死性波形では実機さながらの点滅アラーム表示

### 2. クイズモード
- **波形判読モード**: 動く波形を見て調律名を4択で回答
- **初期対応モード**: 発見時に最初に行うべき対応を4択で回答(ICU実務向け)
- カテゴリ絞り込み・出題数(5/10/15問)・キーボード操作(1–4, Enter)対応
- 同カテゴリの紛らわしい選択肢を優先して出題する distractor ロジック

### 3. 成績・苦手分析
- 波形ごとの正答率を蓄積(ブラウザの localStorage に保存)
- 正答率70%未満の波形を「重点復習リスト」として抽出し、苦手だけでクイズ可能

## 収録波形(21種)

| カテゴリ | 波形 |
|---|---|
| 基本調律 | 正常洞調律 / 洞性頻脈 / 洞性徐脈 |
| 期外収縮 | 心房期外収縮(PAC) / 心室期外収縮(PVC) |
| 上室性不整脈 | 心房細動(AF) / 心房粗動(AFL) / 発作性上室頻拍(PSVT) |
| 房室ブロック・徐脈性 | 1度房室ブロック / ウェンケバッハ型 / モビッツII型 / 完全房室ブロック / 洞停止 |
| 致死性不整脈 | 心室頻拍(VT) / トルサード・ド・ポアンツ / 心室細動(VF) / 心静止 |
| 虚血・電解質・その他 | ST上昇(急性心筋梗塞) / テント状T波(高K血症) / ペースメーカー調律 / 筋電図アーチファクト |

## 技術スタック

- **Vite 7 + React 19 + TypeScript** (strict)
- **Tailwind CSS v4** (CSS-first設定 / `@theme`)
- **Motion** (UIアニメーション) / **Zustand** (状態管理 + persist)
- 波形は画像ではなく、P波・QRS・T波を**ガウシアン成分の和として数学的に合成**し、
  不整脈ごとのリズムロジック(RR揺らぎ・伝導比・PQ漸増・房室解離など)でリアルタイム生成
- Canvas 2D によるスイープ描画(描画ヘッド+消去バー)、Web Audio API による同期音
